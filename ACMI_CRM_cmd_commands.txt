ACMI CRM - Command Prompt (cmd) commands
Run these from the project folder:  cd /d C:\Users\Kemoc\Desktop\ACMI_CRM

=== FIRST-TIME SETUP (run once) ===
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py migrate

=== IMPORT THE OUTREACH WORKBOOK ===
REM dry run (prints counts only, writes nothing)
.venv\Scripts\python.exe manage.py import_workbook
REM actually write the data
.venv\Scripts\python.exe manage.py import_workbook --commit

=== LOCAL LOGIN PASSWORD ===
.venv\Scripts\python.exe manage.py changepassword kellen

=== START THE APP ===
.venv\Scripts\python.exe manage.py runserver
REM then open http://localhost:8000 in your browser (Ctrl+C in the window stops it)

=== GMAIL SYNC ===
REM first, large backlog sync for one user
.venv\Scripts\python.exe manage.py sync_mail --user kellen --all-backlog
REM normal sync (new mail only)
.venv\Scripts\python.exe manage.py sync_mail --user kellen

=== TESTS ===
.venv\Scripts\python.exe manage.py test crm

=== OPTIONAL: CREATE A NEW DJANGO MIGRATION AFTER MODEL CHANGES ===
.venv\Scripts\python.exe manage.py makemigrations
.venv\Scripts\python.exe manage.py migrate

=== NOTES ===
- Copy .env.example to .env and set ACMI_IMAP_PASSWORD_KELLEN (Gmail app password) before syncing mail.
- The workbook is read from Desktop\Prospecting\ACMI_Outreach_Engine.xlsx (add --path "FULL\PATH\FILE.xlsx" to override).
- Set ANTHROPIC_API_KEY in .env for AI summaries.
